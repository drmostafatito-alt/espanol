# حدود المنصة — مُتحقَّق منها رسميًا

**تاريخ التحقق: 2026-10-21.** المصدر الأول: `developers.cloudflare.com` (صفحات Pricing / Limits / Static Assets). الحدود والأسعار تتغير؛ **يجب إعادة التحقق قبل النشر** وفي كل مراجعة كبرى.

## 1. Workers (الخطة المجانية)

| البند | القيمة | المصدر |
| --- | --- | --- |
| الطلبات | 100,000 / يوم (تُصفَّر 00:00 UTC) — بعدها Error 1027 | Workers Limits |
| CPU | **10 ms لكل طلب** (I/O wait لا يُحتسب) | Workers Limits |
| الذاكرة | 128 MB للـ isolate | Workers Limits |
| Subrequests | 50 / طلب | Workers Limits |
| حجم الحزمة | 64 MiB غير مضغوط | Workers Limits |
| ملفات static assets | 20,000 / إصدار · 25 MiB / ملف · **الطلبات إليها مجانية وغير محدودة** | Workers Static Assets |
| Triggers | 5 cron / حساب | Workers Limits |

## 3. R2

| البند | Free |
| --- | --- |
| تخزين | 10 GB-month / شهر |
| Class A (كتابة/سرد) | 1,000,000 / شهر |
| Class B (قراءة) | 10,000,000 / شهر |
| Egress | مجاني دائمًا |

**قاعدة تصميم:** الصوت يُخدَّم من **نطاق مخصص مربوط بـ R2** (أو عبر كاش CDN) لا عبر مسار Worker، حتى لا يستهلك حصة الـ100k طلب/يوم.

## 4. حدود أخرى ذات صلة

- **Pages**: نفس حصة طلبات Workers عند استخدام Functions؛ مشاريع البناء محدودة أيضًا.
- **KV** (إن استُخدم للإعدادات العامة): 100k قراءة/يوم، **1,000 كتابة/يوم** — لذلك لا يُستخدم KV لتخزين عدادات متغيرة.
- **Web Push**: لا خدمة Push مجانية من Cloudflare نفسها. الإرسال يحتاج Worker + مفاتيح VAPID (مجانية) + cron. **غير مضمون على iOS قبل تثبيت PWA** — موثّق للمستخدم.

## 5. ما لا ندّعيه

- لا ندّعي أن الخطة المجانية تكفي عند نمو كبير: 100k طلب/يوم + 100k كتابة D1/يوم سقف حقيقي.
- لا ندّعي أن الحدود ستبقى كما هي؛ القرار المعماري يفترض إمكانية الانتقال إلى Paid ($5/شهر) أو تقليل الاستهلاك.
