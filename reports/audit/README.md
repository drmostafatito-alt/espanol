## 2) ما فُحص فعلًا بآلية (قابل للإثبات)

- **صرامة/بنية:** `isCorrect` منطقي صريح لكل خيار، تطابق `answerKey` مع الأعلام، مفاتيح `errorFeedback`
  تشير إلى خيارات موجودة، معرّفات خيارات فريدة عالميًا، `pos`/`gender` في نطاق المخطط.
- **سلامة النص:** لا كلمة تخلط حروفًا عربية ولاتينية (فساد مثل «Italianا»)، لا حروف عربية في حقول إسبانية،
  توازن `¿…?` و`¡…!`، لا كلمات عربية دخيلة في شرح لا معنى لها فيه.
- **الإجابات:** كل إجابة مقبولة في تمارين الترتيب يمكن بناؤها فعليًا من عناصر التمرين (بالعدد والتكرار)،
  ولا أرقام تعداد تسرّب الترتيب، ولا `correctOptionIds` في تمارين الترتيب.
- **الصوت:** لا مفتاح صوتي مستخدم لنصّين مختلفين (نسبة خاطئة للمتحدث)، وكل المفاتيح `pending/` (لا ملفات مُنتَجة).
- **IPA:** الحقل بصيغة `/…/`، بلا نص عربي، بلا هوامش بين قوسين مثل «(aproximada)»، ومحارفه من مجموعة IPA.
- **التكرار:** لا شرح منسوخ حرفيًا بين تمرينين، ولا نص تمرين مكرر، ولا معيار تقييم منسوخ بين نوعين مختلفين،
  ولا خيارات بنص مكرر/فارغ.
- **الاتساق التربوي:** تعليمات التمرين تسأل عن **الملاءمة** عندما يكون المشتت صحيحًا نحويًا (قاعدة R44).
- **حالة النشر:** كل الدروس `draft`، و`spanishReviewer`/`translationReviewer`/`reviewedAt` = `null`.

## 3) ما لا يفعله هذا التدقيق (حدود معلنة)

1. **لا يحكم على صحة الإسبانية ولا على طبيعتها** — لا مراجع بشري ولا نموذج لغوي معتمد كمرجع.
2. **لا يثبت دقة IPA** — الفحص شكلي (صيغة/محارف/وجود نبر)، وليس حكمًا صواتيًا.
3. **لا يثبت دقة الترجمة العربية** — يكتشف فقط التناقض الصريح والفساد النصي.
4. **لا يقيس المستوى (CEFR)** — «مناسب لـA1» حكم تربوي يحتاج معلمًا.
5. **لا يستبدل المراجعة البشرية** المطلوبة في `docs/CONTENT_REVIEW_QUEUE.md`.

## 4) كيف تُعاد النتائج

```bash
node tools/audit-content-quality.mjs                        # 0 أخطاء / تنبيهات مفتوحة
node tools/audit-content-quality.mjs --json reports/audit/quality.json
npx vitest run tests/content-quality.test.ts               # 21 اختبار انحدار
node tools/validate-content.mjs --dir content/drafts/a1     # (وأخواتها) يجب أن يبقى PASS
```

الأداة تُصدِّر `auditContent(dir)` وتُستدعى من الاختبارات نفسها، فلا يوجد منطق مكرر قد ينحرف.
