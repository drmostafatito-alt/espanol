## 1) تعريف عدّ المفردات (المعيار الرسمي — 8,000)

المرجع الحاسم: `tools/count-lexicon.mjs` (يُولِّد `reports/lexicon-status.md`):

- **الوحدة المعدودة**: مدخل معجمي فريد = قيمة `normalized` لصف `entries[]` في أي `vocab-*.json` تحت `content/drafts/`.
- **ما يُعدّ**: `word` و`expression` و`collocation` و`idiom` — كل منها مدخل واحد (العبارة المتعددة الكلمات = مدخل واحد).
- **ما لا يُعدّ** (مستبعد موثقًا):
  - التصريفات في `forms[]` (صيغ الفعل، الجمع، المؤنث) — تخزَّن داخل المدخل ولا تُضاعف العدد.
  - تكرار المدخل نفسه في الأمثلة أو الجمل أو شروح الدروس.
  - أي تكرار بين الحزم: يُرفض (`validate-content` يرفض التكرار داخل المجلد، و`count-lexicon` يرفضه عالميًا ويستثنيه من العدد الفريد ويسجله في التقرير).
- **المكتمل** = يجتاز مخطط `vocabulary.schema.json` + له `senses` ومعنى فصيح ومثال إسباني يحتوي المدخل (أو صيغته) + الفعل له تصريفات + الاسم له `gender`.
- **المراجَع** = مدخل مرتبط بسجل مراجعة بشرية موثّق — **الحالة الحالية: صفر**، ولا يُرفع إلا بتوثيق حقيقي (بلا ادعاءات).
- **الهدف**: ≥ 8,000 مدخل فريد موزَّعة على PREA1→C1 وفق `content/curriculum/curriculum-map.v1.json`، بلا تحشية (كل مدخل بمعنى عربي فصيح + مصري + مثال طبيعي + خطأ شائع حيث يلزم).

## 3) قواعد ثابتة غير قابلة للتفاوض

1. كل المحتوى `draft` حتى تجتاز بوابات محددة + مراجعة بشرية موثّقة. لا ادعاء مراجعة لم تحدث.
2. لا نشر للإنتاج، ولا لمس الأسرار أو قاعدة الإنتاج أو إعدادات التسجيل دون موافقة صريحة.
3. SEC-02 لا يُتجاوز ولا تُخفَّف متطلباته لتجاوز حدود CPU.
4. لا مفاتيح API في الواجهة، ولا رفع تسجيلات المستخدم دون ضرورة وموافقة.
5. التصحيح على الخادم، ولا مفاتيح إجابة للعميل.
6. لا أعداد جامدة في الاختبارات تجعل نمو المحتوى يسقطها؛ ولا تعديل اختبار ليمر شكليًا.
7. كل دفعة تمر بـ`validate-content` + `audit-content-quality` + `count-lexicon` + vitest + CI أخضر قبل اعتبارها جاهزة.
