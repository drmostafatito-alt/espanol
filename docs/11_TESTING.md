## 7. فرق البيئة الموثّق (مهم)

| الجانب | الاختبارات السريعة (vitest) | اختبار الدخان | الإنتاج |
| --- | --- | --- | --- |
| Runtime | Node 20 + محوّل D1→SQLite (`src/worker/testing/d1-adapter.ts`) | workerd (Miniflare) + D1 محلي | Workers + D1 |
| الغرض | سرعة التغذية الراجعة، منطق المصادقة والصلاحيات | التحقق من التوافق الحقيقي | — |
| الفرق | زمن PBKDF2 وCPU ليسا مطابقين؛ SQLite مكتبة مختلفة | لا يغطي حدود الخطة المجانية | — |

**لماذا:** `wrangler 4` يتطلب Node ≥ 22 والبيئة الحالية 20.20؛ استُخدم `wrangler 3.114` في `tools/wrangler-env` لتشغيل workerd للدخان.
**قاعدة:** أي تغيير في مسار المصادقة/الجلسات لا يُعتبر مكتملًا إلا بمرور `node tools/smoke-worker.mjs` (13/13) بعد `npm run worker:dev`.
