## 3) الدفعات وعلّلها

- **(أ) أمان/منع تسريب + صلاحية قياس:** خلط خادمي، تنقية العرض العام، Placement بالمحاولات، microphone=(self)، نص 409، حد تسجيل الإنتاج. العلّة: أي تقدم يُبنى فوق قياس قابل للاجتياز الأعمى أو مفاتيح مسربة لا قيمة له.
- **(ب) سلامة خادمي حفظ وأداء:** batch ×3، ذرّية submitReview، مؤشرات مشتقة، استقرار eventId، طابور بمستخدم، جلسة عدّادات فقط. العلّة: تكرار/فقدان التقييمات وتجاوز حد D1 كانا سيظهران عند أول استخدام حقيقي.
- **(ج) خط أنابيب المحتوى:** حلّ معجمي شامل في المستورِد مع تقرير بالمتبقي، استيراد الجمل، كاشف الإطارات وتعدين البدائل، تجديد فهرس البحث. العلّة: المنصة كانت تعمل بمحتوى «مستورَد» شكليًا (روابط وأمثلة مفقودة).
- **(د) الصوت:** إصلاحا التشغيل فقط؛ لا ملفات وهمية ولا مزود مدفوع بلا قرار.
- **(هـ) دورة النشر:** بناء المسار مع بقاء كل شيء draft.
- **(و) واجهة وبوابات:** صفحة Placement خادمية، بحث بلا محرك مدمج، درس/مراجعة/لوحة صادقة، حراس CI ونظافة أدوات.
