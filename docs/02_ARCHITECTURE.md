## 1. نظرة عامة

```
                      ┌──────────────────────────────────────────┐
 الهاتف / الكمبيوتر    │  SPA: React 18 + TypeScript + Vite        │
 ┌───────────────┐    │  ├─ وحدات محمّلة تدريجيًا (learn/admin)   │
 │ IndexedDB     │◄──►│  ├─ Service Worker (Workbox يدوي الخصائص) │
 │ (دروس/طابور)  │    │  ├─ Audio player (HTMLAudio + Cache API)  │
 └───────┬───────┘    └──────────────┬───────────────────────────┘
         │                            │ fetch /api/*  (JSON, كوكي جلسة)
         │                            ▼
         │              ┌──────────────────────────────────────┐
         │              │ Worker (Hono-like router خفيف)        │
         │              │  /api/auth  /api/learn  /api/content   │
         │              │  /api/review /api/admin  /api/media    │
         │              │  طبقات: router → auth → validate →    │

         │              └───────┬───────────────┬───────────────┘
         │                      │               │

         │              ┌──────────────┐  ┌──────────────┐
```

## 2. حدود الوحدات (Module boundaries)

| الوحدة | المسؤولية | ما لا تفعله |
| --- | --- | --- |
| `content-core` | أنواع المحتوى + مخططات JSON + مدقق مشترك | لا تعرف D1 |
| `curriculum` | قراءة المسار/الوحدة/الدرس + قاعدة الفتح | لا تحسب XP |
| `exercise-engine` | تعريف أنواع التمارين + التحقق من الإجابة + التغذية الراجعة | لا تكتب تقدمًا بنفسها |
| `progress` | تسجيل المحاولات، حساب الدرجة، الفتح، XP عبر `xp_ledger` | لا تقرر صحة الإجابة |
| `review` (SRS) | SM-2 معدّل، جدولة، استحقاقات | لا تمنح XP |
| `identity` | حسابات، جلسات، أدوار، حدود معدل | لا تلمس المحتوى |
| `media` | توقيع/توجيه الأصول، Alt، ترخيص | لا تخزّن صوتًا في الحزمة |
| `admin` | CRUD محتوى، مراجعة، إعدادات، تدقيق | لا تتجاوز التحقق من الصلاحية |
| `offline` | SW + قائمة عمليات + مزامنة | لا تثق بساعة الجهاز |

**قاعدة:** التقييم (صحة إجابة) يحدث على الخادم. العميل يعرض نتيجة متفائلة ثم يؤكّدها الخادم؛ أي اختلاف يُصحَّح ويُسجَّل.

## 3. تدفقات أساسية

### 3.1 إكمال درس (متصل)
```
POST /api/learn/lessons/:id/attempts   (batch: 5–20 محاولة)
  body: { contentVersionId, attempts:[{eventId, exerciseId, answer, durationMs, startedAt}], clientFinishedAt }
1. جلسة صالحة + ملكية الدرس (لا IDOR)
2. تحميل answer_key الخاص بـ contentVersionId المطلوب (إن اختلف عن الحالي → 409 CONTENT_CHANGED)
3. لكل محاولة: تحقق idempotency (eventId UNIQUE) → تجاهل المكرر
4. تصحيح على الخادم → درجة، أخطاء، تفسيرات
5. transaction: attempts + user_lesson_progress + xp_ledger(+ref) + review_schedule + daily_activity
6. إرجاع: النتيجة المعتمدة، XP الممنوح، ما فُتح، ما استُحق للمراجعة
```
**لا** يقبل الخادم `xp` أو `passed` من العميل.

### 3.2 العمل دون اتصال ثم المزامنة
العميل يخزن المحاولات في `offline_attempts` (IndexedDB) بمفتاح `eventId`. عند العودة يرسل دفعات ≤20 محاولة؛ الخادم يطبّق نفس منطق Idempotency. التفاصيل في `09_OFFLINE_SYNC.md`.

### 3.3 قراءة محتوى درس
`GET /api/content/lessons/:slug?version=latest` → JSON كامل (درس + تمارين + مفردات + مراجع وسائط) قابل للتخزين في IndexedDB. يُخدَّم برأس `Cache-Control: public, max-age=300, stale-while-revalidate=86400` مع `ETag` من `lesson_versions.id`. **لا تُخزَّن استجابات المستخدم في كاش مشترك.**

## 4. استراتيجية الكاش (مفتاح الحدود المجانية)

| النوع | المكان | TTL | ملاحظة |
| --- | --- | --- | --- |
| أصول static (JS/CSS/fonts) | Worker Static Assets + Cache API | سنة (مُبصَّمة hash) | طلباتها مجانية |
| حزمة الدرس العامة | Cache API | 5 دقائق + SWR | مفتاح = slug+version |
| صفحة كلمة/قاموس | Cache API | 1 ساعة | عامة |
| إعدادات الموقع العامة | Cache API | 60 ثانية | تُلغى عند تعديل الإدارة |
| API المستخدم (تقدم/مراجعة) | **بلا كاش** | `no-store` | خاصة |
| الصوت من R2 | نطاق R2 مخصص + Cache | 30 يومًا | لا يستهلك حصة Worker |

**حساب ميزانية الطلبات التقريبي** (متوسط جلسة 12 دقيقة، 6 دروس): ~25 طلب API + 1 حزمة درس + ~15 ملف صوتي (من R2 لا من Worker). أي 100,000 طلب/يوم ≈ 3,500–4,000 جلسة تعلّم يوميًا كحد أقصى مبدئي، وهو كافٍ للإطلاق ومحدود للنمو — موثّق بصدق للمالك.

## 5. الحزمة والتحميل التدريجي

| المسار | الحد المستهدف (gzip) | ملاحظة |
| --- | --- | --- |
| shell عام + الصفحة الرئيسية | ≤ 90 KB | React + router + CSS أساسي |
| وحدة التعلّم | ≤ 120 KB إضافية | تُحمَّل عند أول درس |
| وحدة الإدارة | ≤ 160 KB | **لا تُحمَّل** لمستخدم عادي أبدًا |
| محرك الصوت | ≤ 15 KB | كسول |
| رسوم/أيقونات | SVG مضمّنة | لا مكتبة أيقونات ضخمة |

الخطوط: خط عربي واحد (وزنان) + خط إسباني واحد، `woff2`, `font-display: swap`, تُستضاف محليًا (لا CDN خارجي) — انظر `07_UI_DESIGN_SYSTEM.md`.

## 6. الصوت (بلا TTS مدفوع)

1. **المصدر الأساسي:** ملفات مُولَّدة/مسجَّلة مسبقًا (خارج وقت التشغيل) → Opus 24 kbps أحادي + AAC/MP3 كاحتياط → R2 بمفتاح `audio/{variant}/{hash}.opus`، حيث `hash = sha256(text + voice + variant + speed)`.
2. `audio_assets` تربط النص بالملف؛ تغيير نص جملة يكسر الارتباط → يظهر في تقرير "أصول غير مطابقة النص".
3. التحكم بالسرعة يتم بالتشغيل (`playbackRate`) لا بإعادة التوليد.
4. عند غياب الملف: `SpeechSynthesis` مع لافتة صريحة + النص مكتوبًا + تنبيه في تقرير الجودة.
5. لا صوت داخل الحزمة. تحميل عند الحاجة + تخزين مؤقت + تنزيل مسبق للمقاطع الخمسة التالية فقط.

## 7. المصادقة والجلسات

- كلمة المرور: PBKDF2-HMAC-SHA256 عبر WebCrypto، ملح عشوائي 16 بايت، **عدد التكرارات يُعاير على 10 ms CPU** (قياس فعلي في المرحلة 1). التخزين: `pbkdf2$iterations$salt$hash`.
- الجلسة: توكن عشوائي 32 بايت (base64url) في كوكي `__Host-ses` (HttpOnly, Secure, SameSite=Lax, Path=/). في D1 يُخزَّن **sha256 للتوكن فقط**.
- CSRF: تحقق `Origin`/`Sec-Fetch-Site` لكل طلب غير GET + توكن مزدوج لكوكي الجلسة على العمليات الحساسة.
- حدود المعدل في D1 (`rate_limits`) على: تسجيل الدخول (5/دقيقة/IP-hash + 10/ساعة/حساب)، الاستعادة، التجديد.
- لا JWT في localStorage، لا أسرار في الواجهة.

## 8. البحث والقوائم

- قاموس: بحث بـ`LIKE` على عمود مُطبَّع (`headword_normalized`) بحد 50 بايت نمط (قيد D1) → مسار بديل: جدول `vocabulary_fts` (FTS5 مدعوم في D1) للبحث بالبادئة والجذر.
- كل القوائم مرقّمة (keyset pagination على `(sort, id)`)، بحد أقصى 50 صفًا.
