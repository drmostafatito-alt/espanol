# دليل جودة المحتوى

## 1. مراحل المراجعة العشر (كل درس)

| # | المرحلة | المسؤول | المخرج الإلزامي |
| --- | --- | --- | --- |
| 1 | إنشاء المحتوى | Content Manager | ملف JSON + حالة draft |
| 2 | مراجعة إسبانية | Language Reviewer (ناطق أصلي/مستوى C1+) | `content_review_records(stage='language_es')` |
| 3 | مراجعة الترجمة العربية | مراجع عربي | `stage='translation_ar'` |
| 4 | طبيعية الحوار والتسجيل/السجل | مراجع لغوي | `stage='naturalness'` |
| 5 | ملاءمة المستوى | مصمم منهج | `stage='level_fit'` |
| 6 | صحة مفاتيح الإجابات | مسؤول تقني | `stage='answer_key'` + مدقق آلي |
| 7 | الصوت والصورة | مسؤول وسائط | `stage='media'` + مطابقة نص/صوت |
| 8 | اختبار آلي للتمرين | CI | `node tools/validate-content.mjs` |
| 9 | مراجعة بشرية للعناصر الملتبسة | مراجع أول | `stage='human_final'` |
| 10 | اعتماد النشر | Admin/Reviewer | `stage='publish'` |

## 2. ما يكتشفه المدقق الآلي (وما لا يكتشفه)

| يكتشف | ❌ لا يكتشف |
| --- | --- |
| نقص الحقول الإلزامية، حقل غير معروف (نحو/إملاء بنيوي) | صحة الإسبانية رسميًا أو طبيعتها |
| تكرار المدخل المعجمي باختلاف حالة الأحرف/المسافات | فارقًا دلاليًا دقيقًا بين مترادفين |
| إجابة صحيحة مفقودة أو `isCorrect` غير متسق | ترجمة صحيحة لغويًا لكن غير مناسبة للسياق |
| مشتت بلا تبرير | تلميحًا ذكيًا يكشف الإجابة دلاليًا (مراجعة بشرية) |
| تسريب الإجابة نصيًا في التعليمات | صورة تحتمل معنى آخر |
| مجموع أوزان المعيار ≠ 100 | جودة النموذج الصوتي أو نبرته |
| صوت معلَّق في درس منشور | ملاءمة سيناريو للثقافة المحلية |
| مفردة مستخدمة قبل تدريسها (تقاطع الدروس) | التصريف الصحيح لشاذ نادر (مراجعة بشرية + مصدر) |

**قاعدة صريحة:** لا يُعتمد على نموذج لغوي واحد كدليل صحة نهائي. الأدوات تفحص البنية؛ اللغة تُراجَع بشريًا وتُسنَد إلى معاجم/مراجع في `content_sources`.

## 3. أسلوب الشرح (الفصحى والمصري)

| الحقل | الشرط |
| --- | --- |
| `explanationAr` / `meaningArFusha` / `objectiveAr` | عربية فصحى واضحة، بلا مفردات مترجمة حرفيًا من الإنجليزية |
| `*ArEg` | عامية مصرية طبيعية مختصرة، **اختيارية** وليست بديلًا عن الفصحى |
| `variantNoteAr` | توضيح إسبانيا/أمريكا اللاتينية بعبارة واحدة بلا إرباك |
| مصطلح نحوي | يُشرح بالوظيفة أولًا، ثم يُسمّى: «نستخدم estar هنا لأن الحالة مؤقتة» قبل «estar للأحوال» |

**قواعد كتابة:** لا عامية في فم مراجع المنهج أو في نص الواجهة الرسمي · لا فصحى ثقيلة في ملاحظة مصرية · لا خلط داخل الجملة الواحدة · المصطلح الإسباني بين `«»` مع أول ظهور.

## 4. قائمة فحص الجودة لكل درس (يُقرأ قبل الاعتماد)

1. هل الهدف قابل للقياس بفعل تواصلي؟
2. هل المفردات الجديدة محدودة (6–10) ومناسبة للمستوى؟
3. هل كل مفردة جديدة ظهرت في سياق قبل اختبارها؟
4. هل الأمثلة طبيعية كما يقولها متحدث أصلي، لا ترجمة حرفية من العربية؟
5. هل يوجد تمرين استماع وتعبير (وفق المستوى)؟
6. هل المشتتات مبنية على أخطاء **متوقعة** (mi llamo، una agua، ser/estar)؟
7. هل التفسير يقول **لماذا** الخطأ خطأ، لا فقط «الإجابة الصحيحة هي»؟
8. هل الترجمة العربية تنقل الوظيفة الاجتماعية (طلب/اعتذار/شكوى) لا الكلمات؟
9. هل السيناريو محترم ثقافيًا وخالٍ من الصور النمطية؟
10. هل الصوت مطابق للنص، ومسجّل في `audio_assets.text_hash` الصحيح؟
11. هل للصورة `alt` مفيد ولا تحتمل معنى مضادًا؟
12. هل التمرين يقيس الهدف المعلن فعلًا (لا رياضيات لغوية جانبية)؟
13. هل السجل (formal/informal) موحّد داخل الموقف؟ (خصوصًا الكول سنتر)
14. هل بيانات العميل في السيناريوهات وهمية بالكامل؟
15. هل الأصلح أن يُقسَّم الدرس إلى درسين؟

## 5. تحليل الأخطاء المتوقعة (نموذج عربي ↔ إسباني)

| الخطأ | السبب | المعالجة التعليمية |
| --- | --- | --- |
| «mi llamo» بدل «me llamo» | نقل منطق «اسمي = my name» | تمرين فراغ + تفسير يفرّق بين mi (ملكية) وme (انعكاسي) |
| «soy cansado» | تطبيق ser على كل حالات «يكون» بالعربية | لقطة سياقية ser/estar + تمرين تمييز بمدخلين |
| «una agua» | اعتماد الجنس الظاهر | قاعدة el/un مع الألف المشددة + أمثلة (el aula، el área) |
| نطق h | نقل من الإنجليزية | تدريب صوتي مبكر في PREA1 |
| إسقاط الضمائر الانعكاسية | لا مقابل مباشر في العربية | تمارين انعكاسية سياقية متكررة |
| المقارنة بين «tú/usted» | التبس بالعربية | مسار الإسبانية الرسمية + سيناريوهات كول سنتر |
| «a el» بدل «al» | إسقاط الاندماج | تدريب اندماج a+el، de+el |
| ترجمة «ganas» حرفيًا | تعبير لا يُترجم | تدريس العبارة ككل (collocation) لا كلمات منفصلة |

## 6. سياسة المصادر

- كل مصدر في `content_sources` مع: العنوان، الرابط، الناشر، الترخيص، تاريخ الوصول.
- لا تُنسخ معاجم محمية نصًا حرفيًا. يُستخدم المصدر لتحديد الشيوع/الملاحظات ثم تُصاغ الأمثلة أصليًا.
- إذا لم يوجد مصدر مرخَّص للشيوع: يُوسَم الترتيب `internal_rank` ويُذكر ذلك في الواجهة والإدارة (لا ادعاء علمي).

## 7. البلاغات

بلاغ المستخدم (`content_reports`) بأنواعه الستة يمر إلى `Support Agent` → إن كان لغويًا إلى `Language Reviewer` → إن صحّ: إصدار جديد للدرس + `content_review_records` + إصلاح الأصول + إبلاغ المبلّغ (اختياري بلا بيانات إضافية).
