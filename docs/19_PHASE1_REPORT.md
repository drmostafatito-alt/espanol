## 3. قرارات اتُّخذت أثناء التنفيذ (موثقة)

| القرار | السبب | الأثر |
| --- | --- | --- |
| `wrangler@3.114` في `tools/wrangler-env` منفصل | wrangler 4 يتطلب Node ≥ 22 (البيئة 20.20) | تشغيل workerd/D1 حقيقي للاختبار، بلا تلويث شجرة المشروع |
| محوّل D1→SQLite للاختبارات السريعة | اختبارات الوحدة في Node بسرعة مللي ثانية | **اختلاف بيئة موثّق**، ويُغطّى بـsmoke test على workerd (13/13) |
| `pool: 'forks'` في vitest | better-sqlite3 وحدة أصلية تسبب SIGSEGV داخل worker threads | اختبارات مستقرة |
| `better-sqlite3@11.5.0` | الإصدار 13 لا يعمل على Node 20 (segfault عند التحميل) | مثبت في devDependencies فقط |
| إضافة دور `learner` للمخطط | لم يكن هناك دور للمتعلم العادي أصلًا (ثغرة تصميم اكتُشفت أثناء التنفيذ) | 7 أدوار بدل 6 |
| `PBKDF2_ITERATIONS=20000` | 60k = 17ms > ميزانية 10ms | **حماية أضعف من توصية OWASP — مفاضلة معلنة**؛ رفعها يتطلب الخطة المدفوعة |
| سقف تكرارات 2,000,000 في التحقق | منع إجهاد المعالج بصف تالف | تحصين |
| لا صفحات قانونية بعد | لم تُكتب نصوص معتمدة بعد | موجودة في صفحة الشفافية بواقعية |
| استعادة كلمة المرور معطّلة صراحةً | لم يُعِد المالك مزوّد Resend | الواجهة تقول «غير مفعّل» ولا تدّعي غير ذلك |

## 4. جودة الأداء والإتاحة (المرحلة 1)

- RTL/LTR: كل النصوص الإسبانية داخل `dir="ltr" unicode-bidi: isolate` (صنف `.es`).
- تركيز مرئي دائم، `skip-link`، تسميات حقول، `role="status"`/`role="alert"`، `aria-live` لحالة الصوت.
- أهداف لمس ≥ 44px، واجهة تعمل من 320px (بلا تمرير أفقي).
- `prefers-reduced-motion` مُحترم.
- **لم يُنفَّذ بعد:** فحص axe آلي، اختبار قارئ شاشة يدوي، Lighthouse.

## 6. الخطوة التالية المقترحة (المرحلة 2)

1. **استيراد المحتوى:** `tools/import-content.mjs` → D1 (برامج/وحدات/دروس/إصدارات/تمارين/مفردات) بمعرّفات ثابتة (stableId).
2. **محرك التمارين:** شاشة درس + 8 أنواع أولى + تصحيح على الخادم + `client_event_id` idempotent.
3. **حفظ التقدم:** `user_lesson_progress` + `xp_ledger` بمفاتيح idempotency + فتح الدروس.
4. **اختبارات:** T4–T9 + E2E لدرس A1 النموذجي + اختبار انقطاع الاتصال.

## 7. ملاحظات تشغيل

```bash
# تثبيت (الاعتماديات لا تُحفظ بين الجلسات)
npx pnpm@9 install

# قاعدة البيانات المحلية

# تشغيل التطبيق كاملًا (API + SPA على منفذ واحد)

npm test                      # 45 اختبارًا
node tools/smoke-worker.mjs   # يتطلب worker:dev يعمل
```
