# نظام التصميم البصري

هوية أصلية بالكامل. **ممنوع** نسخ شعار/شخصيات/أيقونات/ألوان أي منتج قائم. المستلهم: مبادئ الوضوح والتدرّج والممارسة، لا الشكل.

> جميع القيم أدناه قابلة للتعديل من الإدارة (`admin_settings` مجموعة `branding`) — ما عدا قيم إتاحة الوصول الأساسية (التباين) التي لا يُسمح بكسرها من الواجهة.

## 1. الفكرة البصرية: «الدفء الأندلسي»

| العنصر | الفكرة | التنفيذ |
| --- | --- | --- |
| الشعار | حرف «Ñ» مجرّد داخل شكل محراب/قوس أندلسي مبسّط، بلا خطوط زائدة | SVG أحادي اللون يعمل بلون واحد وحجم 16px |
| الشخصيات | ثلاث شخصيات أصلية بخطوط بسيطة: **سلمى** (طالبة مصرية)، **دييغو** (طالب إسباني من بلنسية)، **الأستاذة نور** (مدرّبة نطق) | وجوه هندسية بسيطة، تعبيرات واضحة، بلا تفاصيل دقيقة |
| الرسم التوضيحي | خطوط سميكة + مساحة بيضاء + لون واحد مميز لكل مشهد | لا تظليل واقعي، لا تدرجات |
| الأيقونات | مجموعة مخصصة 24px بشبكة 2px | SVG inline، ليست مكتبة جاهزة |

ملاحظة: أسماء الشخصيات وأوصافها مقترح قابل للتغيير من صاحب المشروع.

## 2. الألوان (رموز CSS)

```css
:root {
  --c-primary:        #1F7A5C;  /* أخضر زيتوني هادئ — الفعل الأساسي */
  --c-primary-strong: #155C44;  /* hover/active */
  --c-primary-soft:   #E6F2EC;  /* خلفية شارات */
  --c-accent:         #D97706;  /* كهرماني — سلسلة/XP/تحفيز */
  --c-accent-soft:    #FDF3E4;
  --c-danger:         #B3261E;  /* خطأ — مع أيقونة/نص دائمًا */
  --c-success:        #146C43;
  --c-warn:           #8A5A00;
  --c-bg:             #FAF8F4;  /* عاجي فاتح */
  --c-surface:        #FFFFFF;
  --c-surface-2:      #F2EFE9;
  --c-border:         #DCD6CC;
  --c-text:           #1B1A17;  /* تباين 15:1 على --c-bg */
  --c-text-muted:     #57534A;  /* 7.4:1 */
  --c-focus:          #0B5FFF;  /* حلقة تركيز لا تُخفى */
}
```

**قاعدة التباين:** كل نص أساسي ≥ 4.5:1، والنص الكبير ≥ 3:1. `--c-danger` لا يُستخدم وحده للتعبير عن الخطأ: يجب أيقونة + نص.

## 3. الخطوط

| الاستخدام | الخط | الأوزان | ملاحظة |
| --- | --- | --- | --- |
| العربية | `Noto Kufi Arabic` (بديل: `IBM Plex Sans Arabic`) | 400, 700 | مستضاف محليًا `woff2`, `font-display: swap` |
| الإسبانية/اللاتينية | `Source Sans 3` (بديل: `Inter`) | 400, 600 | أرقام واضحة (مهم للأسعار والوقت) |

**قواعد:** لا أكثر من وزنَين لكل خط · لا تحميل خطوط من CDN خارجي · `line-height` للعربية 1.7–1.8 · حجم النص الأساسي 17px على الهاتف، 16px على الكمبيوتر · `rem` فقط، وتكبير المتصفح يعمل حتى 200%.

## 5. المكوّنات الأساسية

| المكوّن | الحالات الإلزامية |
| --- | --- |
| `Button` | default / hover / active / focus-visible / disabled / loading (نص «جارٍ…» لا دوران فقط) |
| `Card` | عادي / تفاعلي (تركيز واضح) |
| `ExerciseShell` | تعليمات / منطقة تمرين / شريط تقدم / زر «تحقّق» / حالة تصحيح / تفسير |
| `AnswerOption` | محايد / محدد / صحيح / خاطئ / معطّل بعد التحقق — **الشكل + الأيقونة + النص** |
| `AudioButton` | جاهز / يحمّل / يعمل / فاشل (بديل نصي) |
| `RecordButton` | بلا إذن / يطلب / يسجّل / انتهى / مرفوض (سبب واضح) |

## 6. ثنائية الاتجاه (RTL/LTR)

هذا أخطر جزء بصريًا، والقواعد ملزمة:

1. `<html lang="ar" dir="rtl">` للواجهة. والنص الإسباني دائمًا داخل عنصر بسمة `dir="ltr" lang="es"` مع `unicode-bidi: isolate`.
2. لا تُستخدم خصائص `left/right`؛ تُستخدم `margin-inline`, `padding-inline`, `inset-inline`, `border-inline`.
3. الأيقونات الاتجاهية (سهم «التالي») تُقلَب بـ`transform: scaleX(-1)` في RTL، أما أيقونات التشغيل الصوتي فتُبقى كما هي (اتفاق عالمي).
4. علامات ¿ ¡ تُعرض داخل الإسبانية فقط؛ لا تُقلب مواضعها.
5. الأرقام: `font-variant-numeric: tabular-nums` للأسعار والوقت، و`direction: ltr` للأرقام المعزولة.
6. خلط عربي/إسباني داخل جملة واحدة: يُمنع في المحتوى التعليمي. كل جملة إسبانية في فقرة مستقلة أو داخل سياق LTR معزول.
7. الإدخال: حقل الإجابة الإسبانية `dir="ltr" inputmode="text" autocapitalize="off" spellcheck="false"`.

## 7. الحركة

- مدد: 120ms (ميكرو) / 200ms (انتقال) / 300ms (شاشة).
- منحنيات: `cubic-bezier(.2,.7,.3,1)`.
- يُحترم `prefers-reduced-motion: reduce` → إلغاء كل الحركة غير الضرورية.
- ممنوع: وميض، سفّينر يغطي المحتوى، حركة تمنع القراءة.

## 8. الهاتف أولًا (320px)

| البند | القاعدة |
| --- | --- |
| أهداف اللمس | ≥ 44×44 px مع فاصل 8px |
| الشريط السفلي | 4 عناصر: تعلّم · مسارات · مراجعة · حساب — بلا أكثر |
| لوحة المفاتيح | حقل الإجابة يبقى مرئيًا (`scrollIntoView` + `visualViewport`)، ولا يُغطى زر «تحقّق» |
| الحافة الآمنة | `env(safe-area-inset-bottom)` |
| التمرير الأفقي | ممنوع؛ الشاشة 320px حد أدنى مدعوم |
| نص إسباني طويل | يلتف (`overflow-wrap: anywhere`) ولا يُقطع |
| الوضع الأفقي | تُصغَّر المساحات الرأسية، يبقى زر التحقق ظاهرًا |

## 9. الكمبيوتر

- شريط جانبي 240px (يتحول إلى أيقونات 72px عند <1100px).
- منطقة تعلّم بحد أقصى 720px للقراءة.
- لوحة الإدارة شبكة كثيفة (12 عمودًا) وتُحمَّل في حزمة منفصلة.
- اختصارات: `Space` تشغيل الصوت · `Enter` تحقق · `1–4` اختيار خيار · `Esc` إغلاق — مع إمكانية تعطيلها.

## 10. إتاحة الوصول (WCAG 2.2 AA)

- تركيز مرئي دائم (`:focus-visible` بحلقة 3px + إزاحة 2px).
- ترتيب DOM منطقي بلا `tabindex>0`.
- كل صورة لها `alt` (وصفي أو `alt=""` إن كانت زخرفية صريحة).
- الصوت: زر تشغيل/إيقاف + نص بديل + سرعة + إعادة.
- التمارين: تُقرأ بالكامل بقارئ الشاشة (`label` + `aria-describedby` للتفسير)، ونتيجة الصواب/الخطأ تُعلن بـ`role="status"`.
- لا اعتماد على اللون وحده في أي حالة.
- التحدث ليس شرطًا للتقدم؛ يوجد بديل «قيّم نفسك» + تخطي.

## 11. حالات فارغة وحدود

| الحالة | ما يُعرض |
| --- | --- |
| لا إنترنت | لافتة ثابتة + المحتوى المنزَّل + رقم العمليات المنتظرة |
| صوت فاشل | «لم يعمل الصوت» + إعادة + النص + بديل المتصفح إن وُجد |
| ميكروفون مرفوض | شرح السبب + طريقة التفعيل بحسب المتصفح + بديل |
| تخزين ممتلئ | تحذير + إدارة التنزيلات + اقتراح حذف |
| صيانة | صفحة واضحة + رسالة من الإعدادات + لا فقدان بيانات |
