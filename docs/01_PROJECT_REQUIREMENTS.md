# متطلبات المنتج (PRD) — Español بالعربي

الترميز: `FR-xx` وظيفي، `NFR-xx` غير وظيفي، `C-x` قيد إلزامي. كل متطلب مرتبط بمعيار قبول في `12_ACCEPTANCE_MATRIX.md`.

## 1. الأهداف

| # | الهدف | مؤشر قياس |
| --- | --- | --- |
| G1 | يبدأ المتعلم من الصفر (لا يعرف حروف الإسبانية) ويصل إلى C1 | وجود مسار Pre-A1→C1 بأهداف قابلة للاختبار + اختبارات انتقال |
| G2 | التعلّم بالسياق والاستدعاء النشط لا بالحفظ السلبي | كل درس يحتوي ≥4 أنواع تمارين، منها استماع/إنتاج |
| G3 | تقدم محفوظ وموثوق لا يُفقد | 0 حالات فقدان تقدم في اختبارات الانقطاع |
| G4 | عمل مقبول على شبكة ضعيفة/منقطعة | الدروس المنزَّلة + قائمة مزامنة تعمل دون اتصال |
| G5 | مسار مهني حقيقي للكول سنتر | 8 وحدات + محاكاة + معيار تقييم |
| G6 | إدارة محتوى كاملة بلا تعديل كود | إنشاء/مراجعة/نشر درس من لوحة الإدارة |
| G7 | مجاني بالكامل عند الإطلاق | 0 خدمات مدفوعة إلزامية وقت التشغيل |

## 2. المتطلبات الوظيفية (مختصر مُصنَّف)

### الحسابات والجلسات
- `FR-01` إنشاء حساب (بريد + كلمة مرور) مع تحقق من القوة، وبريد غير مكشوف في رسائل الخطأ.
- `FR-02` تسجيل دخول/خروج، جلسة HttpOnly، إبطال جماعي للجلسات.
- `FR-03` استعادة كلمة المرور **فقط عند إعداد مزود بريد**؛ خلاف ذلك تظهر كغير مفعّلة بصدق.
- `FR-04` تعديل الملف الشخصي: الاسم، الصورة الرمزية، أسلوب الشرح (فصحى/مصري/مدمج)، المنطقة الصوتية.
- `FR-05` تصدير البيانات (JSON) وحذف الحساب وفق سياسة.
- `FR-06` أدوار: super_admin / admin / content_manager / language_reviewer / support_agent / analyst — بصلاحيات مختلفة يفرضها الخادم.

### الإعداد الأولي والتقييم
- `FR-07` اختيار المستخدم: "أبدأ من الصفر" أو "اختبار تحديد المستوى" (اختبار تكيفي مبسط بحد أقصى 20 سؤالًا، نتيجته اقتراح لا حكم).
- `FR-08` هدف يومي افتراضي 10 دقائق/20 XP قابل للتعديل.

### التعلم
- `FR-09` خريطة مسار أساسي: Program → Level → Unit → Lesson بفتح مشروط.
- `FR-10` شاشة درس تشغّل تمارين من ≥28 نوعًا (الأنواع المنفذة فعليًا تُوسَم في `12_ACCEPTANCE_MATRIX.md`).
- `FR-11` شاشة نتيجة الدرس: دقة، أخطاء، كلمات جديدة، XP ممنوح من الخادم فقط.
- `FR-12` مكتبة مسارات مستقلة (45 مسارًا مخططًا) لكل منها تقدم مستقل.
- `FR-13` قاموس مفردات: بحث عربي/إسباني، صفحة كلمة (معاني، أمثلة، نطق، ملاحظات، أخطاء شائعة).
- `FR-14` مراجعة يومية بالتكرار المتباعد + قائمة "كلمات صعبة" + مراجعة مسار بعينه.
- `FR-15` استماع: تشغيل كلمة/جملة/حوار، سرعة، إخفاء النص، وضع إملاء.
- `FR-16` تحدث: تسجيل محلي، مقارنة بالنموذج، تخطي دون منع التقدم.
- `FR-17` لوحة المتعلم: مستوى، درس تالٍ، XP، سلسلة، دقة، كلمات متقنة (بتعريفات منفصلة)، مراجعات مستحقة، إنجازات.
- `FR-18` فيديو/نص محادثات موجّهة (نمط "محادثة موجهة" بسيناريو وقواعد تقييم).
- `FR-19` إشعارات داخل الموقع + Web Push اختياري بإذن صريح بعد شرح الفائدة.

### المحتوى والإدارة
- `FR-20` محرر درس/تمرين بمعاينة، تحقق آلي قبل النشر، حالات Draft→In Review→Approved→Published→Archived.
- `FR-21` إصدارات المحتوى: تعديل درس منشور يُنشئ إصدارًا جديدًا ولا يمحو نتائج سابقة.
- `FR-22` إدارة مفردات مع كشف تكرار وربط بالأمثلة والمسارات.
- `FR-23` إدارة أصول (R2) مع Alt وترخيص وفحص ملفات مفقودة.
- `FR-24` إعدادات المنصة: الاسم/الشعار/الألوان/الخطوط/التواصل/السياسات/حدود التقدم/الصيانة.
- `FR-25` إدارة إشعارات (جمهور، موعد، معاينة، نتائج إرسال) بلا تكرار.
- `FR-26` إعلانات: تشغيل/إيقاف، مواضع محددة، بلا حقن JS.
- `FR-27` سجل تدقيق لكل عملية إدارية حساسة.
- `FR-28` استيراد/تصدير JSON/CSV بمخطط مُتحقَّق منه، بلا تأثير على الصلاحيات.

### عدم الاتصال
- `FR-29` PWA: تنزيل وحدة/درس، عمل دون اتصال على المنزَّل، طابور عمليات، مزامنة idempotent، مؤشر حالة.
- `FR-30` إدارة التخزين: حجم التنزيلات، حذف، معالجة امتلاء التخزين.

## 3. المتطلبات غير الوظيفية

| # | المتطلب | الحد |
| --- | --- | --- |
| `NFR-01` | أداء الهاتف: زمن تفاعل أول < 2.5 s على 3G سريع/جهاز متوسط | Lighthouse TTI + قياس فعلي موثق |
| `NFR-02` | حجم JS الأولي للواجهة العامة | < 180 KB gzip (يُقاس) |
| `NFR-03` | إتاحة الوصول | WCAG 2.2 AA، تباين ≥ 4.5:1، تنقل كامل بلوحة المفاتيح |
| `NFR-04` | دعم الشاشات | 320 px → 1920 px، RTL/LTR مختلط |
| `NFR-05` | الأمان | لا أسرار في الواجهة، كل صلاحية تُفحص في الخادم، حدود معدل على المسارات الحساسة |
| `NFR-06` | المتانة | لا فقدان تقدم عند إعادة التحميل/الانقطاع/تغيير الجهاز/تحديث المحتوى |
| `NFR-07` | التكلفة | 0 دولار تشغيلي إلزامي؛ توثيق سقوف الخطة المجانية |
| `NFR-08` | قابلية الصيانة | وثائق مطابقة للتنفيذ، migrations قابلة للتكرار، لا بيانات وهمية كأنها حقيقية |
| `NFR-09` | SEO | صفحات عامة قابلة للفهرسة، صفحات حساب/تقدم `noindex` |
| `NFR-10` | الخصوصية | لا بيع بيانات، لا مشاركة مع معلنين، تسجيلات صوتية محلية بالافتراض |

## 4. القيود الإلزامية

- `C-01` لا أصول أو شخصيات أو واجهة منسوخة من منتج محمي.
- `C-02` لا TTS مدفوع وقت التشغيل، لا قاعدة بيانات خارجية مدفوعة.
- `C-03` المحتوى الحساس (قواعد/أمثلة) لا يُنشر بترجمة آلية غير مراجعة.
- `C-04` الخادم مرجع الحقيقة لـ XP والفتح والإتقان.
- `C-05` لا ادعاء اعتماد CEFR رسمي أو ضمان وظيفة/راتب.
- `C-06` النشر للإنتاج يحتاج تصريحًا صريحًا.

## 5. خارج النطاق (النسخة الأولى، بصدق)

- مكالمات صوتية مباشرة مع مدرّس بشري.
- تقييم نطق آلي بمستوى احترافي (يُستبدل بمقارنة نموذج + استماع ذاتي).
- شهادات معتمدة أو ربط بالسفارات/الجامعات.
- تطبيقات iOS/Android أصلية (PWA فقط).
- ترجمة المنهج إلى لغات أخرى غير العربية (البنية تسمح، المحتوى لا).
